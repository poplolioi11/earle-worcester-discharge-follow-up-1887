# 伍斯特精神病院的離院後追蹤（1887） / It is the End that Crowns the Work — Transcription Dataset

Pliny Earle 在《The Curability of Insanity》的這一節追查伍斯特精神病院 25 名曾被列為康復的住院者。章節保存個別匿名記錄、出院和再入院經過，以及作者如何用長期結果重看早期院方的統計。

In this section of the 1887 edition of The Curability of Insanity, Pliny Earle follows 25 Worcester asylum patients previously counted as recovered. The study preserves anonymized case histories and follows discharge, recurrence, readmission and later outcomes, alongside a printed comparison table.

## Files

- `transcription.txt` retains line and frame markers. Tabs mark table cells. 
- `transcription.json` identifies each frame and text or table unit. A null printed page means no printed page number was recorded. The source links identify the corresponding scan.
- `transcription.tei.xml` maps the same frame text and table cells into TEI P5.
- `review-notes.md` lists review coverage and reading decisions.
